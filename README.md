# Soroready

Radar que avisa a los repos de Stellar antes de que un upgrade trimestral de
protocolo les rompa algo.

## Requisitos

- Node 22
- npm

## Instalación

```bash
cd frontend && npm install
```

## Cómo correrlo

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
